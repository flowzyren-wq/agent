📱 Phone Only Mode

Gak punya laptop? Cuma modal HP tapi mau pakai OpenCode Desktop asli? Bisa banget. Ini caranya.

💡 Konsep: OpenCode itu 2 bagian: Backend Server (4096) + Frontend UI. Di HP, backend bisa jalan di HP itu sendiri (Android) atau di cloud gratis (iOS). Frontend tetap di browser HP, UI tetap asli 100%.
ANDROID - 100% HP ONLY

🤖 Android via Termux

Android bisa jadi server + client sekaligus. HP lu jadi laptop.

1
Install Termux
Download dari F-Droid (jangan Play Store):
f-droid.org/en/packages/com.termux
2
Setup 1 klik
pkg update -y && pkg install -y nodejs git curl curl -fsSL https://opencode.ai/install | bash git clone https://github.com/flowzyren-wq/agent.git opencode-mobile cd opencode-mobile
Atau download script:
📥 Download Setup Script
3
Jalanin 2 terminal
Terminal 1: opencode serve --hostname 0.0.0.0 --port 4096 Terminal 2 (New Session di Termux): cd opencode-mobile && npm start
4
Buka di Chrome HP
http://localhost:3000 (dengan mobile bridge) http://localhost:4096 (langsung)
Add to Home Screen biar jadi app!
iOS - HP ONLY VIA CLOUD

🍎 iPhone / iPad via Cloud Gratis

iOS gak bisa jalanin binary, jadi backend di cloud, frontend di HP.

Opsi 1: Railway (Gratis, 1 Klik)

1
Buka railway.app/new di Safari iPhone
2
Connect repo ini, deploy (Dockerfile udah ada)
3
Dapet URL misal opencode-xxx.up.railway.app → buka di Safari → UI asli muncul!

Opsi 2: GitHub Codespaces (60 jam gratis/bulan)

1
Buka github.com/sst/opencode di Safari
2
Code > Codespaces > Create Codespace
3
Di terminal Codespace: opencode serve --hostname 0.0.0.0 --port 4096
4
Klik popup Port 4096 forwarded > Open in Browser

Opsi 3: Fly.io / Render

Repo ini udah ada Dockerfile, bisa deploy ke Fly.io / Render gratis tier juga.

🎯 Kenapa Tetap UI Asli?

Yang dipertahankan:
  • Layout 3-column desktop
  • Sidebar, file tree, session
  • Editor contenteditable asli
  • Terminal ghostty-web WASM asli
  • Chat, model selection, command palette
  • Semua fitur, bukan tiruan
Yang ditambah (tanpa ubah UI):
  • Touch scrolling momentum
  • Long-press context menu
  • Swipe edge buat sidebar
  • Floating toolbar trigger action asli
  • Keyboard handling biar gak ketutup
  • Safe-area notch iPhone

📲 Cara Pakai di HP (Setelah Jalan)

TOUCH Scroll di sidebar / chat / terminal pake jari (momentum)

SWIPE Swipe dari tepi kiri buat buka sidebar

LONG-PRESS Long-press 500ms di file buat context menu

TOOLBAR Tap tepi bawah buat munculin toolbar: Sidebar, Command Palette (Ctrl+K asli), Terminal (Ctrl+` asli), Esc/Tab/Ctrl

KEYBOARD Tap editor → keyboard muncul, prompt tetap visible (gak ketutup)
